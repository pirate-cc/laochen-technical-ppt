# Content-led layout and reusable style

用于新建页面或已授权的版式调整。先保留本页必要知识与证据，沿用已确认模板和原生动态要求；局部修改只处理涉及的布局与参数。这里提供决策依据，不规定每份稿必须使用多少种版式或另建配置文件。

## Choose a layout from the relationship

在现有页计划中说清主要关系，以及听众必须同时看到哪些对象。先判断信息关系，再选构图；“有四项内容”本身不是选四张卡片的理由。

| 实际内容与阅读任务 | 优先考虑的组织 | 适用条件与拥挤时的调整 | 需要避免 |
| --- | --- | --- | --- |
| 多方案按共同问题比较 | 对齐的比较矩阵、并列面板或同尺度小图 | 共同维度放在相同位置；维度多时用矩阵，少数关键差异可用并列图。不同输出不可强作性能排名 | 每列采用不同指标；把长段落塞进等宽卡片；为完整表格补造数据 |
| 信号、能量或数据传递 | 连续主路径及必要分支，条件邻近相应节点 | 先画真实节点与边；主链过长时按实际子系统分层或折行，保持方向和跨行连接明确 | 用等距方框代替连接语义；箭头穿过标签；把选项画成先后步骤 |
| 实物整体与局部机制 | 总览加对应放大、结构图加局部解释 | 总览保留位置、方向与编号；局部按解释需要扩大，连接标记只承担定位 | 放大图找不到来源位置；缩小整体到无法辨认；示意比例冒充实际尺寸 |
| 公式解释机制或模型差异 | 示意图与变量对应，或按同一维度排列公式、输入与输出 | 保留公式成立条件；运算页让关键中间值可跟随，多模型页对齐可比内容 | 只排公式不解释对象；符号跨图改变含义；因排版删除关键条件 |
| 数据结果与支持的发现 | 主结果图及邻近证据标注；多工况用可比面板 | 比较需要时统一轴、单位和视图；完整数据适合表格时可表图并用，但各自承担不同任务 | 图缩成角落装饰；文字只重复读数；用亮色平均强调所有系列 |
| 时间发展或操作反馈 | 真实时间轴、阶段顺序或对齐的状态变化 | 时间不等距时说明尺度；操作页保留触发、反馈与未变上下文 | 任意等距暗示等时长；缺失的中间状态被编造成真实过程 |
| 少量事实或单个对象介绍 | 直接文字与主图、简洁列表或留白明确的单一构图 | 内容简单即可保持简单；类别无关系时不强行加箭头 | 为变化而加入无含义图标、假流程或额外总结 |

主视觉应使观众认出对象、定位证据或跟随关系，解释紧邻对应部分。不要默认堆叠卡片、标签墙、胶囊标签、圆角框、图标或装饰渐变；不为占位补造内容，也不以大标题、图像面积或留白挤掉必要解释。分组、并列与箭头应准确表达备选、归属、顺序或有来源的因果，不能把相邻设置与报错推成因果。

同一页可组合两种结构，但主次应清楚；同一组比较页可以保持同构，不为“多样性”破坏横向阅读。连续数页出现相同等分布局时，回看信息关系是否真的相同，再决定是否调整。

## Resolve crowding without losing meaning

先定位拥挤原因：必要知识本身多、分组不合理、对象尺度分配错误，还是字体与文本框设置有问题。按本页实际原因选用以下调整，而非机械完成所有步骤：

1. 将同义复述合并，相关条件靠近对应图、公式或节点，保留改变解释含义的信息。
2. 按主要任务分配空间，减少不必要的装饰与固定占位；主图需要更多宽度时调整栏比例，而非把所有栏等分。
3. 根据真实尺寸重排或更换同风格构图。图中标签读不清时先扩大绘图区、改图例位置或用对应局部；不要只放大整个低分辨率截图。
4. 在已约定页数和范围内重新分配内容。需同时比较的对象不要被机械拆散；只有补充细节适合备注，核心解释继续可见。
5. 最后才考虑字号调整，仍按目标观看环境复核。字号、行数、留白比例都不是充分性的替代指标。

## Establish reusable deck parameters

模板已有参数时先提取，不另设一套；自主设计时从第一张有代表性的内容页确认参数，并复用到同稿其他页。复杂公式、长中文标题或图表密集页更能暴露问题，不能仅凭封面判断。

在现有制作脚本、设计笔记或模板样式中记录必要值即可，不强制新增 JSON 或设计文档：

| 参数组 | 应确定的内容 | 使用方式 |
| --- | --- | --- |
| 画布与基准 | 页面尺寸、内容边界、标题基线、正文起点、页码位置（需要时） | 以模板或实际版面为准；页内元素共享明确对齐边，不靠逐个目测摆放 |
| 字体层级 | 中文、Latin、数学字体；标题、正文、图注、数据标签的字号与字重 | 同类角色保持一致；图注、坐标仍须在目标观看尺度可读，不把必要条件降为不可读小字 |
| 间距与文本框 | 内容区间距、组内间距、栏间距、内边距、段距与行距 | 组内通常比组间紧密；比较对象对齐同一基准。每页不重新发明近似值 |
| 色彩含义 | 背景与正文、主要强调、次要信息、固定类别或状态身份 | 同一对象跨页保持对应；主题色不覆盖科学色标与领域惯例，类别另有文字或线型线索 |
| 图与标注 | 图表线宽、连接线/箭头、标记、图例、注释方式与图片处理 | 连接表达真实关系；注释靠近证据，避免数据、单位或坐标被遮住 |

这里的参数是本稿的工作选择，不是跨项目通用数值。需要例外时先说明页面任务为何不同，再调整相关角色；不要把每个例外新增为全局样式。保留用户明确指定的字体、颜色和手工修改。

对文字测量应使用实际字体、字号、字重、框宽、内边距、行段距及换行设置；中文不能只依靠英文单词数估算。最终以保存文件的实际渲染为准。若工具会原地修改样式对象，复用参数值而非共享可变对象。

## Compose for animation states

以上构图同时用于讲演页的入场、中间和终态。先确定需要同时比较的对象，再安排点击，不用逐个文本框出现破坏关系：

- 主路径的节点、指向它的连接和解释按意义协调出现，先有来源再有依赖。
- 比较页展开下一对象时保留共同基准和前一对象；图、公式、数值与其标签同步。
- 证据标注可以逐步出现，原始轴、单位、工况身份保持稳定；过时标注遮挡数据时退场。

不改变 [逐页原生动态](implementation-and-checks.md#progressive-explanation-and-animation) 和实际播放检查要求；单纯终态排版正确不代表中间状态可读。

## References behind these choices

- [MIT AeroAstro Slide Design](https://mitcommlab.mit.edu/aeroastro/commkit/slide-design/)：按受众和观看条件安排视觉层级，保留研究场景所需技术细节。
- [Presentation Zen: Contrast, Repetition, Alignment, Proximity](https://presentationzen.com/blog/design-fundamentals-contrast-repetition-alignment-proximity)：以对比建立主次、重复保持一致、对齐与距离表达关系；这里将原则转成稿内参数和布局判断。
- [Storytelling with Data: Is your point clear?](https://www.storytellingwithdata.com/blog/is-your-point-clear)：从实际问题选择图形和强调，按讲演/独立阅读用途调整解释；汇总不能掩盖本次必须比较的子组差异。

这些是方法参考，不是素材再分发许可或固定排版公式。具体制作仍由本次内容、模板与工具能力决定。
