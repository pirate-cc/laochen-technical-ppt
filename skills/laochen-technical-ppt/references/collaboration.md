# 协作与交接

启用专项子代理时读取。本文件只定义分工、交接与文件所有权；质量标准见 [主规则](../SKILL.md)、相应专业参考和 [制作核对](implementation-and-checks.md#minimum-production-confirmation)。角色名称不扩大授权：审阅只回报，文案/素材任务不写 PPTX。

## Task selection

局部修改或内容、素材、实现均清楚的简单任务由主代理完成。确有独立工作量时，从 A 内容、B 视觉、C 制作、D 模板中选择必要角色；未委派职责由主代理承担。模板已确定或要求原创时不启用 D，用户明确要求协作时按其范围执行。

沿用用户模型设置和现有子代理能力，不创建用户侧聊天。并发总数计入主代理与其他活动代理，角色不等于同时启动名额，专项不再自行委派。D 可与 A 前期并行，完成后释放名额；返修只交相关专项。名额不足时复用、顺序调用或由主代理接回；工具不可用时继续可完成的工作。未启动的角色不能记为已执行。

## Shared brief

复用现有计划或消息，全局约束只写一次：动作与范围、题材/听众及理解目标、讲演/阅读用途、页数或时长、目标应用与目的地、模板或视觉方向、必须保留项、来源限制、权威路径、当前写入方和约定检查方式。提供原材料实际文件/图号/数据位置，不只转述结论。

只为新建、重做或受影响的页面补充：

| 信息 | 必要交接内容 |
| --- | --- |
| 内容与依据 | 稳定页标识、顺序、主体、完整上屏标题/解释、页间依赖；来源、事实状态、单位/定义/条件及结论与工况/指标的对应。标明初稿和待确认项。 |
| 模板与视觉 | 原件/来源、已查看代表页、使用条件、统一样式及中文/公式/图表适配点；素材路径、构图、裁切/图层、原来源/署名或生成提示词、原生编辑要求。区分已取得资源与待验证能力。 |
| 动态与对象 | 入场、点击目标/动作/关联说明、保留上下文及稳定终态；制作方补充对象身份和效果参数。简单页一句话，静态用途不填动画参数。 |

委派消息包括角色、具体页/问题、必要输入、应读章节、输出路径/形式与允许写入的文件，不无差别复制全部聊天和参考。真实缺口才记录受影响页、问题、接手人和恢复条件；不另建强制 JSON、角色目录或管理系统。

## Sequence and file ownership

1. 主代理统一约束。选型时 A 提供内容需求，D 选模板，制作方确认能力；B 可先盘点真实素材，方向未定前不批量生成依赖风格的插画或固化版式。
2. 方向确定后 A/B 按实际材料修订，B/C 确认图层与动态；依赖明确的页即可制作，不必等全套素材，也不拿未确认内容定稿。B 不重新选整套模板，C 不静默更换模板。
3. **启用 C 时，C 独占权威 PPTX 及制作脚本写入；否则由主代理写。** A/B/D 只写分配的内容、素材或选型记录，不覆盖共享笔记和权威稿。复用项目目录，不另出多套最终稿。
4. 新修改先交当前写入方串行完成。转移写入权前，等待其保存并停止后续写入，交回最新路径和未完成项后明确接手；不并发保存、不在保存中途强行接管。
5. 各角色核对自己的交付，当前写入方按 [制作核对](implementation-and-checks.md#minimum-production-confirmation) 检查保存结果。主代理整合事实与完成态；文件存在、脚本成功或角色自报不能当作渲染/播放/人工验收证据。

## Changes and blocked work

需要改变页数、顺序、证据含义、模板或编辑粒度时，专项回交“问题、受影响页、建议”，由主代理在授权内决定并同步依赖。为版式删改关键解释也按此处理，必要知识不能仅留在备注/交接稿。仅超出授权或无法合理解决的关键缺口才询问用户。

失败回交具体操作、错误/原因、可用成果路径、受阻页及恢复条件，继续独立工作，不无依据重试。不得用生成图补真实截图/数据、以视频替代要求的原生编辑、将静态稿称为动态。检查例外按 [三种完成状态](implementation-and-checks.md#check-status-and-exceptions) 记录；协作不扩大修改范围或改变约定交付。

## Handoff examples

**局部替图：** 用户要求“第 5 页换新截图，保留文字和动画，我自己检查”。主代理可直接保留对象和效果目标、替图保存；按用户明确接管的检查范围记录，无需启动专项、重选风格或检查整套 PPT。

**素材与动态重做：** 文案和真实数据已确认时，可仅让 B 准备素材/图层、C 独占制作，主代理协调内容，不用补齐 A/D。若只有一页公式排不下，返修交当前制作方及必要的内容负责人；只有整套方向需改变时才重新协调模板。这些是交接示例，不是已执行结果。
