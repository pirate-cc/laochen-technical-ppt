# 协作与交接

完整 PPT 制作或启用专项子代理时读取。本文件定义内容先行的分工、交接与文件所有权；质量标准见 [主规则](../SKILL.md)、相应专业参考和 [制作核对](implementation-and-checks.md#minimum-production-confirmation)。角色名称不扩大授权：审阅只回报，文案/素材任务不写 PPTX。

## Task selection

完整 PPT 制作默认由主代理统筹 **A 内容与演示文案 → C 制作与动态**；A 是专门的内容作者，负责先说清要演示什么并写出正文，C 根据该内容稿制作。需要独立素材工作时加入 B，需要选模板时加入 D。模板已确定或要求原创时不启用 D；不因使用子代理而新增用户提纲审批。

局部修改、仅审阅、仅文案或素材任务按用户范围由主代理或对应专项完成，不自动启动 A/C 全流程。已有分工的局部返修交原负责人；用户另有协作安排时按其要求执行。子代理不可用时主代理依次承担内容与制作职责，不能把未启动的角色记为已执行。

沿用用户模型设置和现有子代理能力，不创建用户侧聊天。并发总数计入主代理与其他活动代理，角色不等于同时启动名额，专项不再自行委派。A 给出代表页内容后，D 可据此选型；A 继续写稿时 B/D 可按已明确部分工作，完成后释放名额再推进 C。名额不足时复用、顺序调用或由主代理接回，返修只交相关专项。

## Shared brief

复用现有计划或消息，全局约束只写一次：动作与范围、题材/听众及理解目标、讲演/阅读用途、页数或时长、目标应用与目的地、模板或视觉方向、必须保留项、来源限制、权威路径、当前写入方和约定检查方式。提供原材料实际文件/图号/数据位置，不只转述结论。

只为新建、重做或受影响的页面补充：

| 信息 | 必要交接内容 |
| --- | --- |
| 内容与依据 | 整稿主线；每页要演示的对象、过程、方法或结果，观众需要理解什么；稳定页标识、顺序、完整上屏标题与正文及页间承接。说明配图支持哪段正文，保留来源、事实状态、单位/定义/条件及结论与工况/指标的对应。内部待补项与可上屏正文分开。 |
| 模板与视觉 | 原件/来源、已查看代表页、使用条件、统一样式及中文/公式/图表适配点；素材路径、构图、裁切/图层、原来源/署名或生成提示词、原生编辑要求。区分已取得资源与待验证能力。 |
| 动态与对象 | 入场、点击目标/动作/关联说明、保留上下文及稳定终态；制作方补充对象身份和效果参数。简单页一句话，静态用途不填动画参数。 |

委派消息包括角色、具体页/问题、必要输入、应读章节、输出路径/形式与允许写入的文件，不无差别复制全部聊天和参考。真实缺口才记录受影响页、问题、接手人和恢复条件；不另建强制 JSON、角色目录或管理系统。

## Sequence and file ownership

1. 主代理把原材料和约束交 A；A 先定主线与逐页演示任务，再给完整正文和配图需求。主代理核对任务与材料，形成其他专项共用的内容稿，不向用户新增默认审批。
2. B 根据内容稿准备支持素材，D 按代表页正文选模板，C 核实制作能力；A 根据实际素材反馈修订文字。已具备完整正文及必要证据的页即可制作，不必等全稿或全套素材。B 不重新选整套模板，C 不静默更换模板或改写演示主线。
3. **启用 C 时，C 独占权威 PPTX 及制作脚本写入；否则由主代理写。** A/B/D 只写分配的内容、素材或选型记录，不覆盖共享笔记和权威稿。复用项目目录，不另出多套最终稿。
4. 新修改先交当前写入方串行完成。转移写入权前，等待其保存并停止后续写入，交回最新路径和未完成项后明确接手；不并发保存、不在保存中途强行接管。
5. 各角色核对自己的交付，当前写入方按 [制作核对](implementation-and-checks.md#minimum-production-confirmation) 检查保存结果。A 对照实际页面复核正文与演示任务，主代理整合事实和完成态；文件存在、脚本成功或角色自报不能当作渲染/播放/人工验收证据。

## Changes and blocked work

需要改变页数、顺序、证据含义、模板或编辑粒度时，专项回交“问题、受影响页、建议”，由主代理在授权内决定并同步依赖。为版式删改关键解释也按此处理，必要知识不能仅留在备注/交接稿。仅超出授权或无法合理解决的关键缺口才询问用户。

失败回交具体操作、错误/原因、可用成果路径、受阻页及恢复条件，继续独立工作，不无依据重试。不得用生成图补真实截图/数据、以视频替代要求的原生编辑、将静态稿称为动态。检查例外按 [三种完成状态](implementation-and-checks.md#check-status-and-exceptions) 记录；协作不扩大修改范围或改变约定交付。

## Handoff examples

**局部替图：** 用户要求“第 5 页换新截图，保留文字和动画，我自己检查”。主代理可直接保留对象和效果目标、替图保存；按用户明确接管的检查范围记录，无需启动专项、重选风格或检查整套 PPT。

**仅重做素材与动态：** 用户要求保留已确认文案和真实数据时，可仅让 B 准备素材/图层、C 独占制作，主代理保持原内容，不用补齐 A/D。若只有一页公式排不下，返修交当前制作方及必要的内容负责人；只有整套方向需改变时才重新协调模板。这些是交接示例，不是已执行结果。
