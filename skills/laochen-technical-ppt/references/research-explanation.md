# Explanation and Chinese copy

本文件负责讲解顺序、完整正文和配图支持关系。按任务选读；局部修订只处理受影响的含义及必要上下文，审阅按 [任务范围](../SKILL.md#task-scope) 报告。素材获取见 [素材参考](asset-sources.md)，动态实现与检查见 [制作参考](implementation-and-checks.md)。

## Choose the explanation from the scene

先判断听众基础、本次要让观众理解或完成什么，以及讲演或阅读用途。围绕页面任务选择解释路径；前置定义在依赖它的内容之前出现，已有基础可省略。各类任务的必要内容见 [页面角色](#substance-by-page-role)，不把可选路径当作固定大纲。讲述顺序可不同于发生顺序，实际过程关系仍须准确。

## From observation to method

需要由现象引出处理方法时，可沿“原始记录 → 观察现象 → 处理需求 → 方法选择 → 输出解释”组织。操作培训沿实际操作与反馈，产品介绍沿对象与关键特征，历史文化材料沿时间、空间或主题联系；顺序由内容依赖决定。

## Let the materials set the scope

介绍结构、机制、界面或文献时，讲清材料支持的内容即可；未涉及的实验、数据或验证不自动变成缺陷声明。结果状态、比较条件和影响判断的不确定性仍须交代。照片不能证明不可见的内部结构，相关变化不能直接写成因果。

## Substance by page role

| 本页任务 | 必须讲清的内容 | 常见缺口 |
| --- | --- | --- |
| 认识对象或概念 | 身份、具体特征、与已有概念的关系 | 只有名称或抽象评价。 |
| 理解方法或机制 | 输入、关键操作或关系、输出；需要时解释公式、状态或算例 | 只有步骤名，不知道怎样作用。 |
| 执行操作 | 起始条件、对象、动作、反馈与完成状态 | 只有操作名称，没有可观察反馈。 |
| 理解系统或过程 | 组件、连接、输入输出及必要的空间、方向或运动关系 | 装饰图替代实际结构。 |
| 比较对象或结果 | 可比方面、共同条件、具体差异及依据 | 口径不同却排名，或只列对象而不解释差异。 |
| 理解历史、人物或作品 | 有来源的材料及时间、空间、主题联系 | 强套输入输出链。 |
| 作出选择 | 实际目标、证据、选项与取舍 | 无依据的优势清单。 |

一个完整任务可以包含多个相关模型、步骤或图表；按理解需要组合，不按卡片、字数或公式数量判断充实。

## Choose content depth

深度取决于听众看完要能做什么。面向初学者补出前置概念和关键推导；熟悉题材的听众可从差异或证据进入。结果页正文须写出关键观察、比较依据及据此作出的判断，配图供核对现象、条件和量级。现有数据能支持的计算、按已给判据得出的结论应展开；推断说明依据与范围，不补造未经支持的机理、性能或适用范围。

先读原始公式、图注、参数或实现：资料充分却只剩概念名称、笼统评价或无解释图片时，补回 [页面角色](#substance-by-page-role) 所需知识；资料有限则补充必要来源或缩小论述范围。布局前后均保留关键含义，固定页数下先调整组织，不机械拆页。封面和导航按其用途保持简洁。具体示范见 [方法页](worked-examples.md#complete-one-slide-rewrite) 与 [多模型比较](worked-examples.md#comparing-related-models-on-one-slide)。

## Diagnose the explanation gap

先区分缺知识、关系混杂还是显示不清：缺操作或依据就补内容；关系错误就重组；内容完整但难读再调布局。空白本身不是补字或加图的理由。

箭头、分组和邻接须表达真实关系。可选方案不能画成连续步骤；设置与报错相邻，不代表设置导致报错。

## Figure and adjacent explanation

先按本页任务写完整正文，再确定配图承担证据、结构解释、操作定位或情境作用。正文讲清实际工作、做法、关系或判断，图帮助理解或核对这些话；图注、图例与部件名只负责识别，不能充当整页正文。

正文可以是连贯段落、有解释的条目或完整步骤，不强制拆成卡片，也不要求每页重复研究全过程。方法页讲怎样做及用途，结果页讲观察与判断，方案页讲需求与取舍；必要的原因、条件和中间推理不能缩成“提升性能”等标签。图表可承载详细数值和复杂结构，正文保留核心说明，避免逐项抄写图中全部信息。目的、指标或验证计划用正文即可说清时，可以不配内容图片。

配图的局部说明按实际对象处理：

- 照片只说明实际可见的对象，不凭外观补造内部部件。
- 截图明确控件、状态与证据角色，保留必要上下文、单位和警告；可由标题、面板名或邻近文字标明用途。
- 数据图指出趋势、差异及条件；结构图指出连接、方向及作用。

整体图与局部细节按理解需要配合，说明靠近对应证据。问题句或“左图是……、右图是……”不能成为应有正文的替代。示范见 [连续研究案例的方法与结果页](research-and-revision-examples.md#research-argument-across-four-slides)。

## Locating evidence during explanation

| 需要定位的关系 | 合适的提示 |
| --- | --- |
| 点、部件、事件 | 贴近对象的标记、箭头或短标签。 |
| 范围、阶段、区间 | 色带、边界或区域强调。 |
| 组间对应或共同条件 | 分组、括号或对齐。 |
| 局部细节 | 保留整体位置的局部放大。 |

标记位置依据实际图像或数据，引线避开关键内容；区间边界、原始细节及局部放大的来源、单位和尺度变化须可辨。提示、对象和解释同步，已讲的比较上下文继续可见；实际效果实现见 [原生动态](implementation-and-checks.md#progressive-explanation-and-animation)。

## Explain the method in the project

正文讲清方法的输入、关键操作、输出及项目用途，并对应实际物理量；流程图、公式和算例支撑说明，这些关系不要求排成四张卡片。“拟合直线并逐点相减”比“处理：预处理”具体。文献中成立的作用不能写成本项目已取得的性能；参见 [方法页完整改写](worked-examples.md#complete-one-slide-rewrite)。

## Concept comparisons

按对象、输出、输入、假设与适用范围确定可比方面。一个模型输出点值、另一个输出分布时，可比较结构，并在共同条件下比较对应输出；没有共同数据不能排名精度，部分重叠的范围须明确。参见 [不同输出的模型比较](research-and-revision-examples.md#comparing-models-with-different-outputs)。

## Cumulative method chain

串联方法时保留“输入 → A → 中间结果 → B → 输出”，让后一步使用的前一步结果可见；按真实依赖选择协调出现、连接或强调，见 [原生动态](implementation-and-checks.md#progressive-explanation-and-animation)。

## Research presentations

先区分开题、进展、答辩或结题及听众基础，明确计划与已完成工作。用问题、方法、证据、结论建立论证：定位图中对象、条件和指标，区分顺序、并行与基础关系；方法运行成功或中间指标改善，不等于研究目标全部达成。负面和部分达成结果按实际保留，见 [连续研究案例](research-and-revision-examples.md#research-argument-across-four-slides)。

文献按本次问题涉及的对象、方法、条件与结论组织，不用作者年份清单或期刊、日期配额替代比较。按研究类型选择影响解释的已有信息，不把此表变成补做研究的要求：

| 类型 | 解释依赖的信息 |
| --- | --- |
| 实验 | 装置与测量路径、改变和控制的条件、分组与结果。 |
| 理论 | 假设、变量、模型、对应的物理图或算例及验证依据。 |
| 仿真 | 求解方式、材料、边界、网格、输出量与对照条件。 |

同一对象在照片、示意图、公式、表格和结果中身份一致；区分真实装置与理想化模型。多变量变化时不凭结果给单一原因归因。创新性需有比较依据，工作量不自动构成创新；展望由实际结果或边界引出。贡献写实际改动及有证据的收益：增加模型项可说明结构能力，不能自动证明精度提高。

## Copy and asset iteration

先读原材料中的文字、图表与数据，据此写出可上屏正文，再提出各图支持的内容；不把待找的素材当成已有事实。素材到位后核对正文是否准确，材料只支持一部分时补材料、缩小论述或换表达。可以提前盘点素材，不用等全稿定稿；不能让图片库存决定只讲什么，也不能为迁就图片改变事实。

画面拥挤时先调分组、构图和冗余表达，再考虑缩字号，保留必要含义。一页缺图不阻断其他已明确页面；局部改稿阅读相邻上下文。

## Writing from sources

区分原文事实、来源观点和本稿推断；正文表达实际对象、操作与关系，不从摘要补造细节。跨页用对象、概念、时间或数据承接，同一案例再次出现应增加解释。进展以实际记录为准。标题与辅助文字分别按后文专节处理。

**以实质内容组织正文。** 优先写“采用了什么做法、怎样作用、记录到什么、据此怎样判断”，不以“尚未……、不能证明……、不代表……”开头堆出限制清单。内部待补资料留在交接记录；材料未涉及的事项自然收住。结果未达标时直接写指标和差距，计划用“下一轮将……”交代具体行动；会改变读者判断的条件或状态在相关处简短说明一次，避免每页反复声明。不要用泛化保证或防御性话术填补知识缺口。

## Audience-facing qualifications and small text

**标题后默认直接进入实质内容，不例行添加灰色小字副标题、讲述提示或重复总结。** 听众定位和资料制作背景用于内部选材与写作，不自动上屏成为“本科生短课”“教学构造数据”等辅助行；删去后不换位置、改色或放大保留。必要信息优先合入对应输入、图名、轴标或邻近正文；只有确实限定整页且无法自然就近表达的范围、条件或定义，才保留可读副标题。

| 信息作用 | 放置方式 |
| --- | --- |
| 对象、变量、单位、定义与条件 | 随解释对象就近可见；共享定义集中一次，避免标题下和图旁重复。 |
| 会影响读者判断的示例、示意、设计、仿真或实测身份 | 用对象的准确名称自然表达，如“示例输入”“仿真结果”；语境已经清楚时不另加“教学构造”“非实测”“仅供演示”等免责行，也不要求每页重复身份声明。不能把示例冒充实际记录。 |
| 样本、比较口径、不确定性及结果状态 | 放在依赖这些条件的比较或结论附近。 |
| 必要署名、知识归属或明确要求的披露 | 可见简短引用；身份本身属于知识时不能移走，完整书目信息可放备注。 |
| 不改变内容理解的详细来源、生成或制作记录 | 默认放备注。 |
| 讲述顺序、泛化提醒与不影响判断的补充口算 | 放备注或删除；判断所依赖的计算及解释保留在正文。 |

删除的是制作提示和同义复述；实际动作、比较依据与结果含义属于正文，不能因删副标题而一并删去，也不能降成小字图注。不要仅将冗余句放大、换色或改名保留。讲演版与阅读版都须有可见的实质正文，备注帮助讲述，不能代替正文知识。介绍页无需例行写“未验证”等限制语，实际影响理解或判断的状态按上表保留。

## Navigation and supplementary material

封面给出适当身份，长稿按需要导航；短稿不强加目录或过渡页。主内容应足以理解，长推导、参数明细和额外案例只在确有阅读或问答需要时放补充页，不把关键条件全部移走。

答辩问答从实际材料形成有依据的答复；复杂页可准备讲者与证据定位提示。时间不足时先减重复讲述，不删除结论依赖的知识，不编造答辩话术。

## Natural Chinese technical copy

成稿直接说明具体对象、做法和关系，保留必要术语并按听众基础解释。避免抽象名词堆叠、生硬搭配和刻意文艺化，但不以禁词表、对仗、字数或“凑三点”代替判断。连同相邻页通读标题、正文和图注，既自然也准确；文字装得下与表达清楚分别检查。示范见 [中文改写](worked-examples.md#natural-chinese)。

### Titles and cover copy

封面首先标明人物、作品或主题，必要时补范围；保留用户要求的叙事或艺术风格。内部页目标不是成品标题。

| 页面任务 | 默认标题写法 |
| --- | --- |
| 介绍结构、方法、配置、比较原理或归纳内容 | 具体主题短语，如“去均值与线性去趋势”；操作、差别与解释在正文展开。结束页归纳对象或实际所得，不把学习建议写成技术顺序。 |
| 指导操作 | 明确动作与对象；必要顺序或条件保留，如“先保存记录，再关闭程序”。 |
| 回答问题 | 使用正文实际回答的问题，不制造悬念。 |
| 报告已有结果或论证发现 | 有证据的发现句，保留范围，如“本次测试的平均误差降至 2 ms”。 |

技术与教学介绍默认直接命名内容，避免在主题后再接一句泛化概括或讲者安排；这不是禁用冒号、问句或结论标题。实际顺序、因果或反常发现按本页任务表达。“先把……做好，再谈……”“真正关键不是……而是……”若只剩提醒就改成实际对象或关系。

标题保留主题和区分性，不压进整段步骤、数值解释或理由，也不退化成“原理”“结果分析”等空名。章节标签、页标题、图名分清范围，同义重复可合并；已有自然标题和用户指定文字不为统一句式而重写。最后核对标题是否被可见内容支持，必要条件是否保留。对照与反例见 [标题示例](worked-examples.md#titles-from-page-content)。
