# Template selection by presentation needs

用于新建或整体重做且用户未指定模板的任务。已有模板、已确认的整套视觉方向和局部修改沿用现有约定；明确要求原创设计时直接按 [无模板设计](implementation-and-checks.md#working-without-a-template) 执行。仅审阅或文案任务不因此下载模板或制作 PPTX。

模板选型可由主代理完成，有独立检索比较工作量时交给 [D 模板选型](collaboration.md#roles-and-reference-loading)。不同项目按本次题材、听众和内容重新判断，避免把上次使用的模板当作无条件默认；同一份稿使用统一视觉语言，构图按内容变化，不为变化而混用整套模板。

选读：[来源入口](#template-and-component-sources)、[查看与选择](#inspect-and-select)、[适配与交接](#adapt-and-hand-off)。

这些来源可交叉使用，场景不与网站一一绑定。技术/答辩稿重点检查图表、公式和中文解释能否展开；教学/文化稿可寻找与主题匹配的图片、时间线和章节设计；产品/方案稿按实际比较、流程或数据需求选择。整套风格定下后，补充组件也要统一字体、颜色、线条和标注，原始数据与技术关系仍来自本次材料。

订阅、付费、建立新连接或上传私人文件不由模板检索自动授权。遇到访问或许可不适用的候选，换可用来源或在已授权范围内自主设计；不要为使用某个网站而改变用户指定的工具、交付形式或审批安排。

## Inspect and select

1. **从实际内容进入。** 读取题材、听众、用途、页面比例及约定风格，结合 A 或主代理整理的关键内容页需求选候选。常见难点包括长中文标题、成组公式、对照表、真实设备图、复杂流程和图旁说明，不必先写完全稿才开始选型。
2. **查看成套内容。** 查看少量合适候选的实际预览及封面、章节页和代表性内容页，重点检查本次较难容纳的内容。记录实际看过的页，不只依封面或检索缩略图决定。根据缺口换候选，找到匹配方案即可停止，不硬凑候选数量或遍历全部网站。
3. **判断可用性。** 确认实际可取得的文件/服务入口及使用条件，优先合适的可编辑 PPTX 或 POTX。考虑中文字体替换、正文空间、图表尺度、主题元素的干扰和所需图层；模板的“可编辑”“动态”标签不证明本次制作要求已经满足。下载原件后由当前制作方核实所用工具的导入、原对象与图表编辑能力；参考图不能冒称原生模板。
4. **确定整套方向。** 主代理在已有授权内确定适用模板与调整方式；有实际取舍时保留必要备选，不增加默认选型审批。用户指定的确认节点及所选服务的必需选择流程照常执行。合适模板不能保留必要知识或无法满足指定工具要求时，换候选；明确原创或没有合适可用候选时自主设计，不做无依据的反复尝试。

## Adapt and hand off

在已有设计笔记或交接中保留足够信息：选定模板的原始链接和实际文件路径（已取得时）、查看过的代表页、推荐理由、适用许可/署名，以及字体配色、标注和本次主要适配点。明确哪些只是网站说明，哪些已在源文件中确认；不用另建候选数据库。

A 保证必要内容与论证关系，D 选择整套模板和统一方向，B 在选定方向下安排逐页素材、构图与图层，C 或当前写入方确认可实现性并制作。已有合适模板时直接进入相应阶段；D 不重复 B 的逐页素材工作，也不代替 C 写权威 PPTX。分工、名额释放和返修按 [协作规则](collaboration.md#sequence-and-file-ownership) 统一安排。

模板占位符不决定事实、项目指标或段落数量。用真实内容替换后调整版式，必要时借组件库重排某一页，保留整套语言和约定编辑粒度；不为沿用漂亮封面而压缩必要解释。

讲演稿继续按 [逐页原生动态](implementation-and-checks.md#progressive-explanation-and-animation) 安排实际讲解。可复用适合本次内容的模板效果，并按对象、触发和顺序调整；静态模板可以补做原生动态，已有动画也须核对实际目标。封面、过渡及结束页同样按主规则处理，网站预览或“动态模板”标注不替代写入、渲染与播放检查。
