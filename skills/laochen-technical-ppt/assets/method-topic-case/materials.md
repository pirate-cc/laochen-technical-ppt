# 《相机像元与灰度标定》配套材料

[打开六页可编辑旧讲义](source.pptx)。末节为给制作者的改稿请求。

这是一份面向初学者的成像光学综合课旧讲义。像元网格、器件剖面、所有输入读数和重复采样练习均为本例自制。讲义和本文件均可复制、修改、用于教学和公开分发，包括公开分发修改稿。

## 三个像元的原始记录

旧稿第 3 页的网格包含 3 行、4 列。坐标按「行，列」书写，行从上到下、列从左到右，均从 1 开始。D、F、R 三帧按同一坐标配准，只提供下列三个位置的数据，其余格子仅用于定位。

| 像元 | 坐标（行，列） | 遮光暗参考 D / DN | 匀光参考 F / DN | 待测帧 R / DN |
| --- | --- | ---: | ---: | ---: |
| A | （1，2） | 10 | 110 | 60 |
| B | （2，4） | 20 | 220 | 120 |
| C | （3，1） | 20 | 20 | 40 |

DN 是相机输出的数字灰度单位。D 来自遮光条件。拍 F 时，整个网格受到相同且非零的参考照度 E_ref。拍 R 时，场景照度可以随位置变化。三帧使用相同的曝光时间、增益和光学设置，温度固定。对有响应的像元采用理想线性模型，忽略噪声与饱和。另给出失效像元 C 以练习处理无有效系数的输入。

对可用像元 i，令 g_i 为该位置的灰度响应斜率，E_i 为待测照度。在上述设置下，R_i = D_i + g_i E_i，F_i = D_i + g_i E_ref。暗读数 D_i 决定起点，参考增量 F_i − D_i 给出该像元从遮光到参考照度的灰度跨度。

取得参考帧后，可以离线为每个像元计算 Δ_i = F_i − D_i。当 Δ_i > 0 时，保存 k_i = 1/Δ_i 和 D_i，并在有效性掩膜中标出该位置。Δ_i ≤ 0 的像元只标为无效，不保存可用于除法的系数。对于相同设置下新取得的一帧 R，逐个有效位置计算 q_i = (R_i − D_i) × k_i = (R_i − D_i)/(F_i − D_i)。q_i = E_i/E_ref，是相对于参考照度的无量纲亮度。输出保留原行列坐标，无效位置由掩膜标出。

A、B 的参考增量分别为 100、200 DN，待测帧扣暗后分别为 50、100 DN，因此两个有效位置的 q 均为 0.5，对应参考照度的一半。C 的参考增量为 0 DN，缺少可用响应。40 DN 是提供给处理程序的原始输入记录。C 的相对亮度不可推算，其位置应显示为无效。网格其他位置没有提供原始数据，和已知被遮罩的 C 有不同含义。
