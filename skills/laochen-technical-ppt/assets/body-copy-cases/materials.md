# 风机转速采集调试记录

自制教学项目材料，数值用于说明测量方案及取舍，不代表真实设备实测。以下记录、计划和计算定义均为本例的完整来源，不需外部资料。

## 任务及原系统

- 给电控组汇报转速采集模块的当前进展。模块通过霍尔脉冲计数计算转速，控制器将转速送到监控界面。本轮只修改测量统计窗口，没有修改电机控制律，也没有测试整机闭环控制性能。
- 测量链：风机霍尔输出 → 控制器定时计数 → 转速换算 → 监控界面。每转输出 2 个脉冲，计数单位为脉冲个数；固定窗口 T 内计数为 N，转速 r=60N/(2T)，T 以秒计，r 以 r/min 计。
- 供电保持 24 V；同一风机、同一霍尔信号与同一转速换算式。外部转速表提供测试点参照值。
- 当前有两项目标：稳定转速点的显示值与参照差值绝对值不超过 60 r/min；界面获得新独立测量值的间隔不超过 200 ms。两项均需满足。

## 本次已完成的改动

- 原方案使用连续、不重叠的 100 ms 计数窗口，每满一个窗口计算并上传一次新转速值。
- 本次增加可配置的窗口时长，实际试了 500 ms 连续、不重叠窗口；每满一个窗口计算并上传一次新转速值。没有滑动窗口、插值或额外滤波。
- 保留原始脉冲计数、窗口时长、换算转速与上传时刻。100 ms 与 500 ms 两种设置可以切换，没有覆盖原始记录。
- 界面虽然可以重复刷新旧值，但新独立测量值仍需等待计数窗口结束。下面的更新间隔依据上传日志，不是界面重绘周期。
